# MaxMind test databases

`GeoLite2-City-Test.mmdb` and `GeoLite2-ASN-Test.mmdb` are MaxMind's official test
databases from https://github.com/maxmind/MaxMind-DB (`test-data/`), as shipped in
the `maxminddb` 3.2.0 source distribution.

Copyright (c) 2013 - 2026 by MaxMind, Inc. Licensed under the Apache License 2.0 or
the MIT License, at your option; the MIT licence text is in `LICENSE-MIT`.

They contain a small set of fixed sample records (for example 81.2.69.142 -> London,
89.160.20.112 -> Linköping) and are for tests only, not real-world geolocation.
